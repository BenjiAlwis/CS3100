## 3. The .Java Incident

Why do you think a file named `MeasuredIngredient.Java` wouldn't be recognized by the Java compiler? What does this tell you about Java and file naming?

> *Your answer here*
Java file names are case-sensitive and must exactly match the public class name, including capitalization. Because MeasuredIngredient.Java does not match MeasuredIngredient.java, the compiler treats it as an invalid source file. This shows that Java relies on strict naming conventions.
